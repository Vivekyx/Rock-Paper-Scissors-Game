# Rock Paper Scissors – GUI Based Game

This is a GUI-based Rock Paper Scissors game that I developed using Python and Tkinter. In this game, the player competes against the computer by choosing Rock, Paper, or Scissors.

I added a scoring system, winning streak and match result to make the game more interesting.

# Features

- Play against the computer
- Choose Rock, Paper or Scissors
- Computer makes a random choice
- Automatic score calculation
- Track wins, losses and draws
- Winning streak counter
- Best winning streak tracking
- Match ends when a player reaches 3 points
- Reset game option
- Exit game option
- Interactive graphical interface

# Technologies Used

- Python
- Tkinter
- Random Module
